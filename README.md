# Hi3Helper.Plugin.Azurpromilia

**English** · [简体中文](./README.zh-CN.md)

A third-party plugin for [Collapse Launcher](https://collapselauncher.com/) on Windows x64. Download, update, and launch **Azur Promilia** (蓝色星原：旅谣), published by Manjuu.

[GitHub Releases](https://github.com/misaka10843/Hi3Helper.Plugin.Azurpromilia/releases) · [Report an issue](https://github.com/misaka10843/Hi3Helper.Plugin.Azurpromilia/issues)

</div>

> [!IMPORTANT]
> Please report plugin issues in this repository so the maintainer can investigate them directly.

## ✨ Features

- **Version detection** checks the installed client against the published version.
- **Game management** supports discovering existing installations, downloading, installing, launching, and detecting whether the game is running. Public packages are available without signing in through the plugin.
- **Pre-downloads** keep update files in a staging folder and reuse them when that version goes live.
- **File-level updates** reuse matching files and verify or repair files as part of the update. A separate manual repair button and in-launcher game settings are pending.
- **Official backgrounds and news** include static and animated backgrounds, banners, news, notices, and events. The launcher displays the content currently published by Manjuu.
- **Social panel** shows the official QR codes and links, including the web store and customer support when available.

## 🧩 How to Install the Plugin

Use the Windows x64 edition of Collapse Launcher with plugin support. A recent version is recommended for switching static and animated backgrounds.

1. **Download the plugin** ZIP from [GitHub Releases](https://github.com/misaka10843/Hi3Helper.Plugin.Azurpromilia/releases), or build it from source.
2. **Open Plugin Management** from the **Settings** page in Collapse Launcher.
3. **Add and apply** using **Click to add .zip or manifest.json**. Select the ZIP, then restart Collapse Launcher.
4. **Select Azur Promilia** and choose the game installation directory.
